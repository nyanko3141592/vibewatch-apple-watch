FROM ZERO TO VIBE

Download once.
Safari from then on.

The Mac app walks you through every required permission and shows a QR code only one scan away from your controller.

  1. 01
    ↓

    Install the bridge

    Download the notarized Mac app, open the DMG, and drag Vibe Watch Bridge to Applications.

  2. 02
    ⌁

    Flash BLE Micro Pro

    Copy the release UF2 to the board's boot drive, then pair Vibe Watch #1 in macOS Bluetooth.

  3. 03
    M

    Open Codex

    The Mac checklist turns green as soon as the Codex desktop app is detected.

  4. 04
    ⌁

    Scan and control

    Scan the QR. Safari checks all three Mac requirements before enabling the controls.

No guessing. Both the Mac app and iPhone controller tell you exactly what remains: Bridge, BLE device, or Codex.

Inspired by hardware

A great hardware idea,
opened to every iPhone.

GOROman’s Vibe Watch turns frequent Codex decisions into a dedicated wrist interface. This project asks a different question: how much of that experience can we make instantly accessible with the screen already in your pocket?

It preserves the six-agent layout, action layer, event names, and tactile interaction model—then moves the client into the browser.
